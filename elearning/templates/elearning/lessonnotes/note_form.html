How it works
  1. Write your lesson note in Google Docs (or Sheets / Slides, or upload a file to Drive). You need a Google account.
  2. {% if ln_folder_url %}Create it inside the school's lesson-notes folder so the school can open it automatically.{% else %}Share it with the school so reviewers can open it.{% endif %}{% if ln_reviewer_email %} Reviewer account: {{ ln_reviewer_email }}.{% endif %}
  3. Click Share in Google and give the school Editor access (or Commenter if you want to keep edits yourself).
  4. Copy the file's link, paste it here and submit.
  5. The school comments or edits right inside Google, then approves it here or asks for changes.

Paste the link to the file, not to a folder.
